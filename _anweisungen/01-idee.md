# Stufe 1: Idee

Eine Idee ist bewusst kurz — sie dient dem **Festhalten**, nicht dem Refinement.

-   Vorlage: `_anweisungen/vorlagen/idee.md`
-   Ablage: `anforderungen/backlog/<kurzer-name>.md`, Status `idea`
-   Inhalt: nur zwei Aussagen — **was stört oder fehlt** und **was danach anders sein soll**.
-   Eine Idee darf **jeder** festhalten — auch der Agent mitten im Gespräch.
-   Der Agent schärft eine Idee **nicht von sich aus** aus; das passiert erst, wenn der Nutzer sie aufgreift (→ Stufe 2).
-   Wird im Gespräch eine neue Idee oder Erweiterung besprochen, wird sie **zuerst** als Idee festgehalten, bevor Code geschrieben oder geplant wird.

# Projekt

*Beim Anlegen eines Projekts ergänzen: Zweck, Stack, Testbefehle, Build/Deploy, Besonderheiten.*

## Stack

*Zweck, Sprache/Framework, Build, Auslieferung.*

## Befehle

*Tests (alle, einzeln), Prüflauf der UI-Richtlinie, lokal starten, Deploy.*

## Release

*Projektabhängig, vom Nutzer festgelegt — z. B. „jeder Commit auf main ist live" oder „Branch je Anforderung, Merge = Release".*

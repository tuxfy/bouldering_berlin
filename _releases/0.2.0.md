# Notizen

Erstes für App-Nutzer sichtbares Tool:

-   **Boulder Log** — in der Tool-Übersicht der Startseite erreichbar. Einen geschafften (oder versuchten) Boulder in einer Zeile eintragen: Grad (mit Vorschlagsliste der Fb-Skala, freie Eingabe bleibt möglich), tries, send, Style-Tags und ein Freitextfeld für weitere Angaben.
-   Alle Einträge stehen als **Klartext-Log** untereinander — frei **bearbeitbar** (die einzige Möglichkeit zum Korrigieren/Löschen einzelner Zeilen), **kopierbar** per Button, und über „Reset" (mit Rückfrage) komplett leerbar.
-   **Daten bleiben auf dem Gerät** und sind **offline** nutzbar; keine Hallen-Auswahl, keine Session-Historie — genau ein aktuelles Log.

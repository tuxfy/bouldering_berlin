# Projekt

**Bouldering Berlin Toolkit** — eine Sammlung kleiner, mobiler Tools rund ums Bouldern, ausgeliefert als **eine** installierbare, offline-fähige PWA (iPhone/Safari, nur Dark Mode, Bedienung mit einer Hand). Build-frei: native ES-Module und Web Components, keine Laufzeit-Abhängigkeiten. Einzelne Tools (Boulder-Log, Timer, …) folgen als eigene Anforderungen; dieses Repo ist die gemeinsame Grundlage.

**Vor jeder Arbeit lesen:** [Prozessregeln](_agent-process/AGENTS.md). Sie gelten für alle Arbeit in diesem Projekt; diese Datei ergänzt sie nur.
